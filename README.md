# 💰 Java Expense Tracker

A simple and user-friendly **console-based Expense Tracker application built using Java**.

This project helps users add, view, search, calculate, and delete their daily expenses.

## ✨ Features

- ➕ Add Expense
- 📋 View All Expenses
- 💰 Calculate Total Expense
- 🔍 Search Expense by Category
- 🗑️ Delete Expense
- 🚪 Exit Application

## 🛠️ Technologies Used

- Java
- OOP Concepts
- ArrayList
- Scanner
- Git & GitHub
